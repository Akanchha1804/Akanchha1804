## Featured Projects

### 🔬 PrognosAI — Predictive Maintenance System

An AI-driven predictive maintenance platform built using sensor data from the **NASA C-MAPSS dataset** to estimate Remaining Useful Life (RUL) and monitor equipment health.

**Highlights**
- Machine learning models for RUL prediction
- Feature engineering and data preprocessing
- FastAPI-based prediction backend
- PostgreSQL database for prediction and engine data
- Grafana dashboards for fleet health and model monitoring
- Docker-based development environment

**Tech:** `Python` `Scikit-learn` `XGBoost` `FastAPI` `PostgreSQL` `Grafana` `Docker`

### 🛒 Retail Shelf Monitoring

A computer vision system designed to monitor retail shelves and detect products using **YOLOv8**.

**Highlights**
- Object detection using YOLOv8
- Trained on a subset of the SKU-110K dataset
- Real-time product detection and shelf monitoring
- Shelf-level product counting
- Restocking intelligence and analytics
- Deployed as a web application

**Tech:** `Python` `YOLOv8` `OpenCV` `Computer Vision`

🔗 [Live Demo](https://retail-shelf-monitoring.vercel.app)
